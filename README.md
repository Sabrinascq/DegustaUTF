**DESCRIÇÃO DO PROJETO E DIVISÃO DE FUNÇÕES**
O projeto desenvolvido na disciplina de Programação Back-end tem como objetivo o desenvolvimento de uma plataforma web que possa funcionar como coletânea de receitas culinárias entre os alunos da universidade, a equipe focou em desenvolver um sistema web simples e funcional, que exibisse e também exigisse dos alunos somente o necessário, um login e conhecimentos culinários. 
A divisão de trabalho da equipe ocorreu por uma organização em pacotes de funcionalidades, ou seja, cada membro foi responsável por desenvolver um funcionalidade(receitas, comentários) e após isso os membros foram unindo os códigos e consertando os erros encontrados.
